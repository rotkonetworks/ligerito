# ligerito

Ligerito, a polynomial commitment scheme over binary extension fields, and
the crates it is built from:

- `ligerito` — prover and verifier
- `ligerito-binary-fields` — GF(2^32) / GF(2^128) arithmetic
- `ligerito-merkle` — Merkle trees for the commitments
- `ligerito-reed-solomon` — Reed-Solomon encoding over binary fields

Published on crates.io. These crates lived in
[zcli](https://github.com/rotkonetworks/zcli) under `crates/` until
2026-10; this repository carries their history from there.
